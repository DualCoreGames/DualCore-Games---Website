01  /  Urban Environment study

Delhi City Environment

Unity Bakery Lightmapper PC Target

Designing a city environment is focused on controlling spatial rhythms—believable streets, height variations, and intersections that organically reveal metropolitan structures. This project captures the density of a busy urban layout while staying highly optimized for real-time rendering.

Key Design Choices:

  • Monotony Breaks: Structural height variation breaks up the metropolitan skyline.
  • Gradual Reveal: Street layouts are organized so the environment loads without visual pop-ins or heavy processing stutters.
  • Bakery Lightmapping: High-fidelity lightmaps baked manually using Bakery to completely eliminate expensive real-time calculations.
Performance Snapshot
Target Frame Rate 70–90 FPS stable rendering
Draw Calls ~210 batch count limit
Polygons ~160k triangles limit
Optimizations Texture atlasing, Occlusion culling, Modular assets
02  /  Terrain Environment Study

Mountain Road Racing Level

Unity Splines PC & Mobile Foliage LODs

A scenic driving highway designed to balance high-speed gameplay mechanics with massive terrain scales. Turn curvatures are calculated to mimic mountain roads, giving players clear sightlines for driving maneuvers at high speeds.

Key Design Choices:

  • Spline-Based Road Layout: Generating natural road curves wrapping dynamically around elevation details.
  • Foliage Performance: Vegetation density is strictly managed with custom LOD parameters adjusting based on distances.
  • Lightweight Shaders: Water surfaces and reflection planes rely on customized lightweight shaders to minimize GPU pixel overhead.
System Specifications
Environment Type Spline Racing Highway
Target Platforms PC & Mobile cross-compatibility
Geometry Baking Distant mesh detail optimizations
LOD Tuning Dynamic vegetation density control
03  /  Low-Poly Level Study

Mobile Platformer Level

Unity Mobile Low-Poly Assets Stylized Post-Process

A stylized platformer level designed for mobile devices. The key design focus centers around visual readability, clear platform spacing, and open sightlines, ensuring players can navigate smoothly without mechanical confusion.

Key Design Choices:

  • Readability First: Clean platform spaces and color-graded highlights guide player directions naturally.
  • Mobile Budgeting: Low-poly geometric designs preserve rendering budgets on older mobile devices.
  • Atmospheric Polish: Soft light setups combined with localized post-processing color grading yield visual polish without hardware stress.
Mobile Specs
Asset Style Stylized Low-Poly Geometry
Visual Tuning Post-processing & Color Grading
Framerate Target 60 FPS locked on mobile chipsets
Inputs Supported Mobile touchscreen controls layout
04  /  Environment Design Study

Scenic Park Level Design

Unreal Engine 5 Foliage Placement Lumen Lighting

A detailed scenic park environment study designed to explore natural landscapes, path progression, and realistic lighting inside Unreal Engine 5. Pathing curves are laid out to guide user gaze towards focal points naturally.

Key Design Choices:

  • Organic Layout: Curving stone pathways and dense vegetation lines create natural exploration paths.
  • Dynamic Lighting: Powered by Unreal Engine's Lumen for real-time global illumination and indirect sky reflections.
  • Foliage Density: Managed via custom collision parameters and paint layers to prevent performance drops.

Engine Pipeline Unreal Engine 5 Lumen GI
Asset Workflow High-poly nanite meshes & foliage painting
Target Platforms PC & Next-Gen Console hardware
